# Pro reports

* **Show PostgreSQL Lock Risks**: PostgreSQL operations that block reads or writes or rewrite a table, with the safer way to write them.
* **Show Rollback Plan**: A down migration for everything that can be reversed, and a list of what cannot.

The first Pro command starts a free 14-day trial on this computer. After the trial, Pro is a one-time purchase: USD 19 (Personal) or USD 39 per user (Business).
